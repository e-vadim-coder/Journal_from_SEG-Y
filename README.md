# SEG-Y → XLSX журнал

Преобразует SEG-Y файлы в таблицу Microsoft Excel (XLSX) с датами, временем и
координатами начала и конца записи.

## Назначение

Программа предназначена для геофизиков и обработчиков сейсмических данных.
Позволяет быстро составить журнал полевых наблюдений по набору SEG-Y файлов:
извлекает из заголовков трасс дату, время, географические координаты источника
(WGS84) и метрические координаты CDP, сортирует файлы по дате и номеру профиля,
а также выявляет аномалии в заголовках.

## Требования

- Python 3.13+
- openpyxl (устанавливается: `pip install openpyxl`)

## Установка

1. Поместите файл `segy2journal.py` в любой каталог.
2. Убедитесь, что openpyxl установлен: `pip install openpyxl`
3. (опционально) Поместите файлы `.sgy`/`.segy` в отдельный каталог.

## Использование

### С диалоговым окном (проще)

```
py -3 segy2journal.py
```

Откроется окно выбора файлов Windows. Выберите один или несколько SEG-Y файлов.
Журнал сохранится в том же каталоге, откуда взят первый файл.

### Из командной строки (без диалога)

```
py -3 segy2journal.py "D:\data\наблюдения"
```

Будут обработаны все `.sgy` и `.segy` файлы в указанном каталоге и его
подкаталогах.

### Параметры

| Параметр | Описание |
|----------|----------|
| `directory` | Каталог с SEG-Y файлами (если не указан — диалог) |
| `-o ФАЙЛ` | Имя выходного XLSX (по умолч. `segy_journal.xlsx`) |
| `--no-recursive` | Не сканировать подкаталоги |
| `--list-formats` | Показать коды форматов данных SEG-Y и выйти |

## Что извлекается из каждого файла

Поля читаются из trace-заголовка первой и последней трассы (согласно
спецификации SEG-Y rev. 1, отсчёт байт с 1):

**Время:**
- Год (байты 157–158)
- День года (159–160)
- Час (161–162)
- Минута (163–164)
- Секунда (165–166)

**Географические координаты источника (WGS84, градусы):**
- Долгота Source X (байты 73–76) — в секундах, делится на 3600
- Широта Source Y (байты 77–80) — в секундах, делится на 3600

**Метрические координаты CDP (метры):**
- X (байты 181–184)
- Y (байты 185–188)

**Применение скаляра (байты 69–70):**
- Отрицательный скаляр → значение делится на `|scalar|`
- Положительный скаляр → значение умножается на `scalar`
- Всегда степень 10 (1, 10, 100, 1000...)

**Порядок байт:**
- Бинарный заголовок — всегда big-endian (стандарт SEG-Y)
- Порядок байт в заголовках трасс определяется автоматически по эвристике:
  год, день года, часы, минуты, секунды, скаляр и номер трассы в файле

**Количество трасс** вычисляется из размера файла (seek), без последовательного
чтения всех трасс.

## Сортировка

Если в имени файла распознаётся дата и номер, файлы сортируются по возрастанию
даты и номера. Поддерживаемые форматы имён:

| Формат | Пример |
|--------|--------|
| `XXXXX_YYYY_MM_DD_NNN` | `PROFILE_2026_05_15_001.sgy` |
| `XXXXX_YYMMDD_NN` | `ABP60_250416_10.sgy` |
| `YYYYMMDD_NN` | `20260515_1.sgy` |

Файлы без даты в имени помещаются в конец таблицы.

## Формат выходного XLSX

Лист «Журнал SEG-Y» с колонками:

1. № п/п
2. Файл
3. Дата (из имени)
4. Номер (из имени)
5. Начало записи (DD.MM.YYYY HH:MM:SS)
6. Конец записи
7. Количество трасс
8. Длина трассы (отсчётов)
9. Интервал дискретизации (мкс)
10–11. Долгота/Широта WGS84 (°) — начало
12–13. Долгота/Широта WGS84 (°) — конец
14–15. X/Y (CDP), м — начало
16–17. X/Y (CDP), м — конец
18. Примечания

- Заголовки закреплены (freeze panes)
- Автофильтр
- Чередование цвета строк (зebra striping)
- Числовой формат «0.000000» для градусов, «0.0########» для метров
- Аномальные ячейки с красной заливкой

## Обнаружение аномалий

Программа проверяет каждый файл на три типа проблем:

1. **Нули в заголовке** — поля времени или координат равны 0
2. **Некорректные значения** — год, день года, часы и т.д. не проходят
   проверку диапазона (например год = −5888 — признак неверного порядка байт)
3. **Координаты вне допустимых границ** — широта за пределами ±90°,
   долгота за пределами ±180°, CDP координаты > 10⁷ метров

Результаты:
- В XLSX аномальные ячейки выделяются красной заливкой и красным текстом,
  в колонку «Примечания» записывается описание
- Рядом с XLSX создаётся файл `segy_journal_protocol.txt` со сводкой по всем
  аномалиям: какие поля, какие значения, характер ошибки

## Пример

```
D:\data\ABP60\
├── ABP60_250416_1.sgy   (11784 трассы, start=2025-04-16 04:16:48, 20.70°E 55.26°N, CDP=481065/6123693)
├── ABP60_250416_2.sgy   (6113 трассы, start=2025-04-16 04:46:16, ...)
└── ...

> py -3 segy2journal.py D:\data\ABP60 -o journal.xlsx
```

## Примечания

- Файл журнала при ошибке доступа (занят другой программой) автоматически
  сохраняется с суффиксом `_1`, `_2` и т.д.
- Протокол аномалий создаётся только если есть файлы с аномалиями
- Программа не модифицирует исходные SEG-Y файлы
